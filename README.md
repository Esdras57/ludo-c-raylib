# Ludo em C (Raylib)

Projeto de um jogo de Ludo multiplataforma (Linux, Windows e macOS) desenvolvido em linguagem C com a biblioteca gráfica Raylib.

## Status do Projeto

🚧 **Em planejamento e arquitetura** — Mapeamento de fluxos, regras e estruturação modular do repositório.

## Estrutura de Pastas

- `include/` — Arquivos de cabeçalho (`.h`) com estruturas e definições.
- `src/` — Implementação da lógica do jogo e interface gráfica.
- `assets/` — Recursos visuais e sonoros.
- `.github/workflows/` — Automação de compilação multiplataforma.
